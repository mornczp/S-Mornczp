# Todo
Todo 是做[[250504-规划|规划]]的工具。
Todo 的基本单位是 [[Projects]]。
## 模块功能描述
模块：[[Todo]]
列出目前正在进行，且没有完成、暂停的项目表格。
1. 限制检索 type 属性：检索笔记库 `02-Projects` 路径下 type 属性（type 不一定存在值）为 `"[[Projects]]"` 的笔记项目。
2. 限制隐藏 finished 属性、suspended 属性有值：隐藏已完成、已暂停的笔记项目，即只显示进行中的笔记。
3. 限制检索 tags 属性：不为“长期项目”、且是“summary”的项目笔记。
4. 显示项目最后更新时间，按最后更新时间降序排列笔记。
5. 显示笔记的类别，其值为 categories 的值。
## 使用
每月及每年总结的时候，分析本月、年任务的完成情况。
发现的任务再记录到 Todo。
期间无法做完的写到 Todo，在[[Projects]]中立项，并在当天日记记录。
